# Services Directory

Thư mục chứa các service thành phần trong hệ thống. Mỗi service có thể là một repo độc lập hoặc sub-project trong monorepo.

## Danh sách Service:
1. **`api/`**: Backend API viết bằng Java Spring Boot (Maven), port `8080`.
   - Xem chi tiết tại: [api/README.md](./api/README.md)
2. **`web/`**: Frontend UI viết bằng React 18 Vite (Node.js), port `5173`.
   - Xem chi tiết tại: [web/README.md](./web/README.md)
