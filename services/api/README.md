# Backend Service (API)

Đây là Backend mô phỏng hệ thống Spring Boot (Java 17+). Cung cấp các endpoint gây lỗi cố ý phục vụ cho kiểm thử tính năng tự phục hồi của AI Agent.

## Môi trường & Build Tool
- Java 17+
- Maven

## Lệnh thông dụng
- Build: `./mvnw clean package`
- Chạy Test: `./mvnw clean test`
- Khởi động cục bộ: `./mvnw spring-boot:run`
